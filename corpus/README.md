# Corpus

The corpus is an evidentiary ledger, not a reading list and not a collection of titles assumed to contain a predetermined doctrine.

`index.yaml` records what has been identified, how it was identified, whether an exact witness has been acquired, and whether that witness has actually been read. Discovery, acquisition, page-pinning, reading, interpretation, and ratification are separate acts.

A remote artifact is not silently treated as preserved repository content. Each acquisition record states whether the exact artifact is retained, its cryptographic digest when available, and the authority that digest does and does not confer.

Copyrighted works are not committed merely because they are needed. Lawful access and exact-edition records must be established separately. `NOT_ACQUIRED` means only that this repository does not yet possess a governed witness; it makes no claim about the work's availability or contents.
